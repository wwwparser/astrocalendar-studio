# Доработки после полной сверки требований — 1.7.0

Последний критерий малых тел около звёзд: строго **менее 10 угловых минут**. Ровно 10′ не проходит. Кометам/астероидам необходимо быть не слабее +13m, звёздам — +7m. Пример 10P–Фомальгаут с расстоянием 11′ исключён по этому правилу.

## Что изменилось

- Кометный минимум звёздной величины на сетке выбранного месяца называется «наибольший ожидаемый блеск в этом месяце». Начало октября больше не объявляется глобальным максимумом 10P. Оценка не выдаётся за измерение.
- Lunar X/V содержат фазу и угловой диаметр Луны. Окно ±2 часа проверяется по опорным городам всей России, включая Камчатку. Публикуются города, а не ложное обобщение по Москве/Краснодару.
- Добавлены окна низкого освещения Прямой стены, Альпийской долины, кратеров Тихо и Коперник, Апеннин. Критерий: высота Солнца 3° над сферическим горизонтом центра детали, видимая сторона Луны, местная высота Луны ≥10°, Солнца ≤−6°. Окно ±4 часа. Это геометрическая подсказка наблюдателю, а не DEM-модель рельефа или точное время появления теней.
- МКС — Москва, ККС — Сочи. Начало и окончание каждой утренней/вечерней серии считаются отдельно. Расчёт захватывает соседние дни за пределами месяца, чтобы не назвать началом первый попавшийся день выпуска. При возрасте TLE >3 суток время в опубликованной строке скрывается, >10 суток событие техническое.
- Для отобранных CNEOS-сближений получен прогноз APmag Horizons в окне ±7 суток с шагом 20 минут. Показан самый яркий отсчёт этого окна, источник и граница окна сохраняются. H не подставляется вместо V. При отсутствии APmag явно указано «блеск неизвестен». Геоцентрический максимум не обещает наблюдаемость в городе.
- Добавлена элонгация и северное/южное положение относительно Солнца для распознанных небесных целей. Правила <25°/25–50°/>50° — подсказка, не замена высоты, сумерек и географии. Пуски, станционные серии и события без позиции не получают выдуманного значения.
- RMS-кандидаты теперь проходят проверку ночных контактов по опорным городам. Основные планеты считаются по DE440s, Титан/Тритон — по Horizons. Для карточек используется отдельный semantic category, исходный Gaia G сохранён как G. Кандидаты слабее G=13 остаются в контрольном отчёте. Контакты получают REVIEW и не публикуются автоматически.
- Общие имена DSO оформлены кавычками «…».
- Настоящие custom emoji Стаса экспортируются кнопкой «TG HTML» в GUI и ссылкой на HTML в веб-редакторе. Источник — идентификаторы из его сообщения, не похожие Unicode-значки. Обычные TXT/clipboard используют Unicode. HTML предназначен для Telegram API, простая вставка текста HTML не превращает его в custom emoji.

## Ограничения, которые нельзя скрыть

1. Планетные контакты используют сферический лимб: кольца, атмосферное ослабление и сплюснутость не моделируются. Позиции звёзд взяты из RMS на эпоху события; это не новый независимый fit Gaia. REVIEW обязателен.
2. Покрытие астероидом 14723 из контрольного списка всё ещё не подтверждено уточнённой осью. Нельзя вручную превратить его в подтверждённое без объяснения расхождения.
3. Полнота России не доказывается набором городов. Лунные покрытия используют также сетку 2°, но узкие касательные полосы требуют отдельного расчёта. Независимый каталог in-the-sky на момент работы закрыл доступ защитой Anubis. Это внешний источник проверки, не основание выдумывать отсутствующие события.
4. Occult4 и старый Harvard-каталог отдельно не запускаются: проект использует собственное ядро и открытый RMS. NAOJ остаётся ссылкой для независимой ручной проверки.
5. Астероидный перечень ограничен поддерживаемыми объектами, а блеск комет — источниками наблюдений и моделями. Нельзя обещать исчерпывающий каталог всех малых тел.
6. Отправка custom emoji через Bot API зависит от разрешений Telegram для бота; по умолчанию выключена. `TELEGRAM_CUSTOM_EMOJI=1` включает HTML только для подходящего бота. Отправок при разработке не было.
