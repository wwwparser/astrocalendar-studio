ASTROCALENDAR STUDIO 1.7.0 — ПОРТАТИВНАЯ ВЕРСИЯ ДЛЯ СТАСА

Windows 10/11, 64-bit. Установка программы и Python не требуются.

1. Скачайте AstroCalendarStudio-1.7.0-Stas-Portable.zip из Assets:
https://github.com/wwwparser/astrocalendar-studio/releases/tag/v1.7.0
Не выбирайте Source code — это исходники, а не готовая программа.

2. Распакуйте архив целиком, например в C:\AstroCalendarStudio-Stas.
Не запускайте exe внутри ZIP и не переносите его отдельно от _internal.
Используйте папку, в которую у Вас есть право записи, вне Program Files.

3. Откройте файл AstroCalendarStudio.exe в распакованной папке.
Если Windows попросит проверить издателя, проверьте, что архив скачан
именно из указанного репозитория. Сборка не подписана сертификатом.

4. При первом запуске согласитесь скачать данные. Можно также открыть
вкладку «Данные» и нажать «Скачать недостающее» — около 138 МБ.
Для либраций и лунного рельефа нажмите
«Скачать всё, включая необязательное» — ещё около 56 МБ.
Во время загрузки нужен интернет. Данные будут лежать в data/ рядом с exe.
Внешние прогнозы, пуски и Live также требуют интернета для обновления.

5. Чтобы получить октябрь: выберите 2026 год, октябрь, нужный город
и режим «Месячный выпуск». Нажмите «Рассчитать» и дождитесь окончания.
Часть источников обновляется по сети; расчёт может занять несколько минут.

6. Снимайте галочки с ненужных событий, редактируйте формулировки.
В Telegram preview проверяйте результат и копируйте каждую часть отдельно.
Длинный выпуск автоматически делится между событиями, лимит — 4096.
События с REVIEW нужно проверить перед публикацией.

7. «Файл» → «Сохранить состояние» (Ctrl+S) сохраняет редакторские правки.
«Сохранить выходные файлы» (Ctrl+Shift+S) создаёт календарь и отчёты.
Состояние хранится в workspace/, результаты и версии — в out/.
Настройки окна сохраняются отдельно в настройках Windows (QSettings):
при переносе на другой компьютер геометрия окна не переносится.

8. Готовый октябрь уже есть в папке «Октябрь 2026»:
calendar_2026-10_v006.txt — весь выпуск;
calendar_2026-10_v007.md — версия с форматированием;
telegram_2026-10_part_1.txt — part_4.txt — четыре сообщения для Telegram;
QA_REPORT_2026-10.md — замечания и проверка.
Эти готовые файлы можно прочитать без скачивания данных и без расчёта.

9. При обновлении закройте программу, распакуйте новую версию отдельно,
перенесите в неё свои data/, workspace/ и out/. Не удаляйте старую папку,
пока не проверите сохранённые выпуски. Личные ключи и переписка в архив
не входят. TNS Live требует Ваших TNS_API_KEY, TNS_BOT_ID и TNS_BOT_NAME.

10. Для удаления достаточно удалить папку программы.
Для резервной копии сохраняйте всю папку, особенно workspace/.
